# Indico Developments

Portuguese-first website for Indico Developments in Mozambique, with an English language option. Includes villas, resorts, lodges, renovations and bespoke interiors, plus ten illustrative project concepts.

## Preview

Open `index.html` in your browser, or serve this folder with `python3 -m http.server 4173`. No build or dependencies are required.

## Deployment

Deploy this folder as a static website. The entry point is `index.html`; images are in `assets/`.

## Content notes

Images are AI-generated architectural concepts inspired by Mozambique, not photographs of exact locations or completed projects. The project form downloads a text brief locally; it does not submit enquiries to a server. Google Fonts are loaded externally.
